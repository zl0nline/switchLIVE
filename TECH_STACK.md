# Технологический стек

## Язык
**Python 3**

Минимум зависимостей — основа на стандартной библиотеке.

## Зависимости

| Пакет | Назначение |
|-------|-----------|
| `pyserial` | Работа с COM-портами (консольный кабель) |

Внешние бинарники:
- `iperf3` — тест трафика (запускается через `subprocess`)

## Стандартная библиотека (без доп. пакетов)

- `sqlite3` — история тестов
- `subprocess` — запуск iperf3, консольные команды
- `csv`, `html` — отчёты
- `configparser` / `json` — конфиги
- `re` — парсинг CLI-вывода коммутаторов

## UI / TUI

Красивый консольный интерфейс — важно для удобства оператора:
- цветной вывод, иконки, эмодзи;
- прогресс-бары при тестировании портов;
- анимации/спиннеры при ожидании COM-порта, ответа коммутатора и загрузки PoE-камеры;
- понятные статусы: OK / WARN / FAIL;
- таблицы с результатами по портам;
- понятные сообщения на русском языке без лишнего технического шума.

Подход:
- сначала пробуем простой ANSI/стандартную библиотеку, если этого хватает;
- `rich` можно добавить как лёгкую UX-зависимость для красивого вывода, таблиц, прогресс-баров и цветов;
- `textual` не тащим в MVP, только если позже действительно понадобится полноценный интерактивный TUI.

## Принципы

- Минимум сторонних пакетов
- Адаптеры под модели — простой Python-код, легко править
- Красивый, понятный UI — оператор работает с утилитой весь день
- Консольный интерфейс должен быть приятным: статусы, цвета, прогресс-бары, спиннеры и иконки, сначала средствами ANSI/стандартной библиотеки
- Если позже понадобится «один бинарник без окружения» — PyInstaller или переписываем ядро на Go
